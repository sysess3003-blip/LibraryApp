# Отчёт о тестировании LibraryApp

## Объект тестирования
Консольное приложение LibraryApp на C# / .NET 8 для хранения книг, выдачи, возврата и поиска по идентификатору. Классы: Book, Library.

## Методика тестирования
Ручной запуск трёх проблемных сценариев в LibraryApp.Buggy; отладка через точки останова, F10/F11, «Локальные» и «Контрольные значения»; сравнение с исправленной реализацией в LibraryApp; статическая инспекция кода и анализаторы Visual Studio.

## Найденные дефекты
| ID | Описание | Шаги воспроизведения | Ожидаемый результат | Фактический результат в исходной версии | Статус |
|---|---|---|---|---|---|
| D-01 | Не обработан поиск отсутствующей книги | LibraryApp.Buggy, аргумент `missing`; вызов `BorrowBook(999)` | Сообщение «книга не найдена» | `NullReferenceException` при обращении к `book.IsAvailable` | Исправлен в LibraryApp |
| D-02 | Повторная выдача разрешена | LibraryApp.Buggy, аргумент `repeat`; дважды `BorrowBook(1)` | Отказ при повторном запросе | Повторное сообщение об успешной выдаче | Исправлен в LibraryApp |
| D-03 | Возврат ранее невыданной книги | LibraryApp.Buggy, аргумент `return`; вызов `ReturnBook(2)` | Отказ: книга не была выдана | Сообщение об успешном возврате | Исправлен в LibraryApp |

## Результаты инспекции кода
- Исходная версия: отсутствуют проверки `null`, состояния `IsAvailable`, XML-комментарии публичных методов, коллекция не `readonly`.
- Исправленная версия: добавлены проверки существования и состояния, XML-документация, `readonly` для списка, PascalCase для типов/методов и camelCase для локальных переменных/параметров.
- Для проверки анализаторов проект настроен с `EnableNETAnalyzers` и `AnalysisLevel`.

## Итоги
В коде исправлены три заложенных дефекта; для подтверждения результатов необходимы реальные запуски в Visual Studio. Автоматизированные тесты и количественная оценка покрытия в данном задании не предусмотрены и не выполнялись. Рекомендовано позднее добавить xUnit-тесты для пограничных сценариев.
